# 🚀 راهنمای ران کردن پنل - قدم به قدم (فارسی)

## روش 1: همین الان بدون نصب (30 ثانیه)
1. فایل `index.html` را دانلود کن
2. دوبار کلیک کن → در مرورگر باز می‌شود
3. شماره بزن → کد `1234` → وارد شو
> **همین الان کار می‌کند!** نیازی به سرور نیست. برای تست و نمایش.

---

## روش 2: ران کردن حرفه‌ای روی کامپیوتر خودت (2 دقیقه)
```bash
# 1. Node.js را نصب کن از nodejs.org (اگر نداری)

# 2. ترمینال را باز کن در پوشه ceo-dashboard
cd ceo-dashboard

# 3. نصب
npm install

# 4. فایل .env را بساز
cp .env.example .env
# بعد .env را با Notepad باز کن و کلیدهای باسلام/تلگرام را وارد کن

# 5. ران
npm start

# 6. باز کن
http://localhost:3000
```
✅ پنل روی کامپیوترت ران شد! تا ترمینال باز است آنلاین است.

## روش 3: روی اینترنت (دامنه اختصاصی) - پیشنهاد اصلی
### گزینه A: لیارا (ایرانی، ساده)
1. برو `liara.ir` → ثبت نام
2. `ایجاد برنامه` → Node.js → نام `ceo-panel`
3. همین پوشه را zip کن و آپلود کن
4. دامنه `panel.yourstore.ir` را وصل کن + SSL رایگان فعال کن
5. در بخش `متغیرها` مقادیر `.env` را وارد کن
6. تمام! `https://panel.yourstore.ir` فقط برای توست

### گزینه B: ورسل (رایگان، سریع)
1. برو `vercel.com` → با گیت‌هاب لاگین
2. `Add New Project` → همین پوشه را آپلود
3. در `Environment Variables` مقادیر `.env` را بگذار
4. Deploy → لینک `https://ceo-panel.vercel.app` را بگیر → دامنه خودت را وصل کن

## 🔗 اتصال به برنامه‌ها - کلیدها را از کجا بیارم؟

### 1) باسلام (واریز پول)
- برو `basalam.com` → ورود → غرفه من → تنظیمات → API / وب‌هوک
- `ایجاد کلید جدید` → کپی کن → در `.env` بگذار `BASALAM_API_KEY`
- وب‌هوک را بگذار: `https://panel.yourstore.ir/api/basalam-hook`
- از این به بعد هر سفارش جدید اتومات به پنل می‌آید

### 2) تلگرام (پیام تایید روی گوشی)
- در تلگرام به `@BotFather` پیام بده: `/newbot`
- نام بگذار: `YourStore Bot` → توکن مثل `123456:AAH...` را کپی کن
- به `@userinfobot` پیام بده → آیدی عددی خودت را بگیر
- در `.env` بگذار:
```
TELEGRAM_BOT_TOKEN=123456:AAH...
TELEGRAM_ADMIN_CHAT_ID=123456789
```

### 3) اینستاگرام (تولید محتوا)
- پیج را Business کن + به صفحه فیسبوک وصل کن
- برو `developers.facebook.com` → My Apps → Create App → Business
- محصول `Instagram Graph API` را اضافه کن
- Access Token بگیر → در `.env` بگذار

> اگر سخت بود، فقط باسلام و تلگرام را وصل کن، اینستا را بعدا من برات وصل می‌کنم.

## 🔒 امنیت - فقط برای خودت
در `.env`:
```
ALLOWED_PHONE=+98912XXXXXXX  # فقط همین شماره می‌تواند وارد شود
ALLOWED_DOMAIN=panel.yourstore.ir  # فقط روی همین دامنه کار کند
```
بعد از این، حتی اگر کسی لینک پنل را داشته باشد، بدون شماره تو نمی‌تواند وارد شود.
