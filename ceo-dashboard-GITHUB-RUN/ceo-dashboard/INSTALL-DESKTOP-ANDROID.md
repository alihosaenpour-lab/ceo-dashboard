# 📱💻 نصب پنل CEO روی دسکتاپ و اندروید

## روش 1: نصب فوری (PWA) - بدون نیاز به برنامه‌نویسی - 10 ثانیه
**این روش هم روی کامپیوتر و هم روی گوشی کار می‌کند و پیشنهاد اصلی است.**

### روی اندروید (گوشی):
1. با گوشی برو به آدرس پنل: `https://panel.yourstore.ir` یا همین `index.html` را روی هاست بذار
2. مرورگر کروم → منو ⋮ (سه نقطه بالا) → **"افزودن به صفحه اصلی"** یا **"Install app"**
3. تمام! آیکون پنل مثل بقیه اپ‌ها روی گوشی می‌آید، با یک کلیک باز می‌شود، حتی آفلاین کار می‌کند.

### روی کامپیوتر (ویندوز/مک):
1. با کروم/Edge برو به آدرس پنل
2. کنار آدرس بار، آیکون **نصب** (🖥️+) ظاهر می‌شود → کلیک کن → **Install**
3. یا منو ⋮ → **Install CEO Panel**
4. پنل مثل یک برنامه واقعی روی دسکتاپ/Taskbar می‌آید، نوتیفیکیشن هم دارد.

> **دکمه نصب در هدر پنل:** اگر مرورگر اجازه دهد، دکمه سبز "📲 نصب روی گوشی/دسکتاپ" در بالای پنل ظاهر می‌شود، بزن نصب می‌شود.

## روش 2: اپلیکیشن دسکتاپ واقعی (Electron) - فایل .exe

برای داشتن فایل `CEO-Panel-Setup.exe` که مثل هر برنامه ویندوزی نصب شود:

```bash
cd ceo-dashboard

# 1. نصب ابزار
npm install

# 2. ران به صورت اپ دسکتاپ (تست)
npm run desktop
# یک پنجره دسکتاپ باز می‌شود - دقیقا همین پنل ولی بدون مرورگر!

# 3. ساخت فایل نصب ویندوز/مک/لینوکس
npm run desktop:build
# خروجی در پوشه dist/ :
# - CEO Panel Setup 2.0.0.exe (ویندوز)
# - CEO Panel-2.0.0.dmg (مک)
# - CEO Panel-2.0.0.AppImage (لینوکس)
```

**ویژگی‌ها:**
- آیکون اختصاصی در دسکتاپ
- اجرا بدون مرورگر، سریع‌تر
- آپدیت خودکار
- فقط با شماره شما باز می‌شود (امن)

## روش 3: اپلیکیشن اندروید واقعی (APK) - فایل .apk

برای داشتن فایل `ceo-panel.apk` که روی هر گوشی اندروید نصب شود:

```bash
cd ceo-dashboard

# 1. نصب کپسیتر
npm install

# 2. اضافه کردن اندروید (فقط بار اول - نیاز به Android Studio)
npm run android:init

# 3. کپی فایل‌ها به پروژه اندروید
npm run android:build

# 4. باز کردن در اندروید استودیو و ساخت APK
npm run android:open
# در Android Studio: Build → Build APK → APK در پوشه android/app/build/outputs/apk/debug/app-debug.apk

# یا دستور مستقیم:
cd android && ./gradlew assembleDebug
```

**خروجی:** `app-debug.apk` را به گوشی بفرست، نصب کن. آیکون پنل می‌آید.

**بدون Android Studio (ساده‌تر):**
- برو به `https://www.pwabuilder.com`
- آدرس سایت پنل را بده → `Build My PWA` → `Android` → دانلود APK

## تست PWA همین الان در همین محیط:
1. همین `index.html` را با کروم باز کن
2. `F12` → تب `Application` → `Manifest` را ببین
3. آیکون و Service Worker فعال است.
