# 💻 نسخه دسکتاپ - CEO Panel

## ✅ همین الان بدون نصب - 5 ثانیه

**روش فوری (PWA) - بدون فایل exe:**

1. همین `index.html` را با **کروم یا Edge** باز کن
2. منو ⋮ → **Install app** یا آیکون نصب کنار آدرس بار
3. تمام! پنل مثل برنامه واقعی روی دسکتاپ می‌آید

**یا با سرور:**
```bash
npm start
# برو http://localhost:3000
# بعد منو → Install
```

---

## 📦 روش حرفه‌ای - فایل EXE ویندوز

برای داشتن `CEO-Panel-Setup.exe` مثل هر برنامه ویندوزی:

### روی ویندوز خودت (2 دقیقه):

1. **Node.js** را نصب کن از `nodejs.org` (اگر نداری)
2. پوشه `ceo-dashboard` را به دسکتاپ کپی کن
3. روی `BUILD-DESKTOP.bat` دوبار کلیک کن
   - خودش `npm install` می‌زند
   - بعد `CEO Panel Setup 2.0.0.exe` را در `dist/` می‌سازد
4. فایل `dist/CEO Panel Setup 2.0.0.exe` را اجرا کن → نصب می‌شود

**دستی:**
```bash
cd ceo-dashboard
npm install
npx electron-builder --win --publish never
# خروجی: dist/CEO Panel Setup 2.0.0.exe
```

### اجرای بدون نصب (Portable):
```bash
npm run desktop
# یک پنجره دسکتاپ بدون مرورگر باز می‌شود
```

## 🚀 ران سریع دسکتاپ (بدون بیلد)

**ویندوز:**
- روی `CEO-Panel-Desktop.bat` دوبار کلیک کن
- کروم در حالت اپ باز می‌شود (بدون نوار مرورگر، مثل برنامه)

**مک/لینوکس:**
```bash
chmod +x CEO-Panel-Desktop.sh
./CEO-Panel-Desktop.sh
```

**نیاز:** Node.js + Chrome نصب باشد + سرور ران باشد (`npm start`)
