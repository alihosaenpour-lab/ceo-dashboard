🔐 امنیت اختصاصی شما

1

فقط شماره شما

در فایل config.js شماره‌تان را قفل کنید: ALLOWED_PHONE="0912..." — هیچ شماره دیگری حتی با کد وارد نمی‌شود.

2

دامنه اختصاصی + SSL

پنل فقط روی دامنه شما (مثلا panel.yourstore.ir) با HTTPS کار کند. بقیه دامنه‌ها بلاک.

3

اتصال امن API

کلیدهای باسلام/اینستا/تلگرام فقط در سرور (env) ذخیره می‌شود، نه در مرورگر.

BASALAM_API_KEY=xxxxx
TELEGRAM_BOT_TOKEN=xxxxx
INSTAGRAM_ACCESS_TOKEN=xxxxx
ALLOWED_PHONE=+98...

▶️ چطور ران کنم - گام به گام

A

اجرای فوری (همین الان)

همین فایل index.html را دانلود کن و دوبار کلیک کن — بدون نصب، روی کامپیوترت اجرا می‌شود.

B

روی هاست/سرور (حرفه‌ای)

1) فایل را در هاست آپلود کن
2) دامنه + SSL بگیر (رایگان با Let's Encrypt)
3) فایل .env را با کلیدهای باسلام/تلگرام پر کن
4) تمام — پنل اختصاصی توست.

git clone ...
npm i && npm run start
# یا فقط آپلود index.html روی هاست
C

باسلام چطور وصل می‌شود؟

از پنل باسلام → تنظیمات → API → کلید بگیر → اینجا وارد کن. بعد محصولاتت اتومات همگام، سفارشات اتومات می‌آید، پول به حساب شما می‌رود.

🎯 چرخه جذب و فروش اتومات (حرفه‌ای)

1) AI هر روز 2 محتوا می‌سازد (پست + استوری) → 2) هشتگ و کپشن جذاب + لینک باسلام → 3) مشتری از اینستا وارد باسلام می‌شود → 4) خرید می‌کند → 5) پول به حساب شما + پیام تایید برای شما → 6) AI پشتیبانی و ارسال را انجام می‌دهد.
