## 🚀 شروع سریع (۵ دقیقه)

### ۱) ایمپورت در n8n

**راه ساده — از داخل خود n8n:**
1. n8n را باز کن → **Workflows** → دکمهٔ **Import from File** (یا سه‌نقطهٔ بالا-راست → Import)
2. فایل‌های یکی از پوشه‌ها را انتخاب کن (می‌توانی چند فایل را هم‌زمان انتخاب کنی)
3. ورک‌فلو با حالت **غیرفعال** ایمپورت می‌شود — تا وقتی اعتبارنامه‌ها را وصل نکردی فعالش نکن (`active: false` در همهٔ فایل‌ها)

**راه حرفه‌ای — خط فرمان (برای ایمپورت دسته‌ای):**
```bash
# همهٔ ورک‌فلوهای یک تیم را یک‌جا وارد کن
n8n import:workflow --separate --input=./n8n-money-team/03-telegram

# یا فقط یک فایل
n8n import:workflow --input=./n8n-money-team/03-telegram/01-telegram-agent-text-audio-images.json

# لیست آنچه وارد شد
n8n list:workflow
```

**روی dgx/داکر:**
```bash
docker exec -it <container> n8n import:workflow --separate --input=/data/n8n-money-team
```

### ۲) اعتبارنامه‌ها را وصل کن
بعد از ایمپورت، n8n برای هر گرهٔ بی‌اعتبارنامه یک علامت هشدار قرمز می‌دهد. روی گره کلیک کن → `Credential` → سرویس را وصل کن.
رایج‌ترین‌ها در این ۷۵ ورک‌فلو:

| سرویس | چند ورک‌فلو لازمش دارد | از کجا بگیرم |
|-------|:---:|---------------|
| ربات تلگرام | ۲۹ | `@BotFather` در تلگرام → `/newbot` |
| حساب Google (OAuth) | ۳۱ | Google Cloud Console → OAuth Client |
| کلید OpenAI | ۲ + همهٔ ایجنت‌ها | platform.openai.com |
| HTTP Request (کلیدهای مختلف) | ۴۲ | داخل خود ورک‌فلو ببین کدام API صدا زده می‌شود |
| وردپرس | ۵ | پروفایل وردپرس → Application Passwords |
| Airtable / HubSpot / Slack | ۶ / ۶ / ۴ | پنل خودشان |
| Instagram + Facebook Graph | ۴ | Meta for Developers → App + توکن بلندمدت |
| X (توییتر) | ۶ | developer.x.com |
| Stripe / Gumroad / PayPal | ۳ / ۳ / ۱ | پنل خودشان |

> ⚠️ نکته: بعضی ورک‌فلوهای تولید ویدیو (Kling، Midjourney، Flux، Creatomate، Blotato، ElevenLabs) سرویس **پول‌دار/اشتراکی** می‌خواهند. اول با تلگرام/محتوا شروع کن (رایگان‌ترند) و بر اساس مشتری، سرویس پول‌دار را اضافه کن.

## 💵 چطور از این تیم پول دربیاید؟ (۳ مسیر روشن)

### مسیر ۱ — آژانس محتوا و شبکه‌های اجتماعی (سریع‌ترین درآمد)
**با:** `01-content-factory` + `02-instagram-social` + `05-money-ops/03`
- برای هر کافی‌شاپ/آرایشگاه/کلینیک/فروشگاه یک بستهٔ ماهانه ببند: ۲۰ پست + ۸ ریلز + ۴ مقالهٔ سئو.
- کل تولید و انتشار خودکار است؛ تو فقط تایید نهایی می‌کنی.
- پیشنهاد قیمت: اشتراک **ماهانه** (مثلاً ۵ تا ۱۵ میلیون تومان به‌ازای هر مشتری، بسته به بازار خودت) — با ۵ مشتری، درآمد ماهانهٔ تکراری داری.
- فاکتور و پرداخت: `05-money-ops/03` (فرم + Stripe/Zoom) یا لینک پرداخت ایرانی.

### مسیر ۲ — فروش ربات و دستیار AI به کسب‌وکارها (حاشیهٔ سود بالا)
**با:** `03-telegram` (کل تیم) + `04-leads-sales/17`
- «دستیار هوشمند + پشتیبانی ۲۴ ساعته + پاسخ به سوالات از روی اسناد مشتری» را به‌عنوان محصول بفروش.
- ورک‌فلوهای آماده: `03-telegram/04` (همه‌کاره)، `03-telegram/10` (روی اسناد مشتری)، `03-telegram/15` (چند مشتری هم‌زمان).
- مدل درآمد: **راه‌اندازی + اشتراک ماهانهٔ نگهداری**. این همان چیزی است که مشتری هر ماه پولش را می‌دهد.
- مزیت بازار ایران: تلگرام نصب پیش‌فرض همه است — نرخ پذیرش بالاتر از اپ اختصاصی.

### مسیر ۳ — سیستم لید و فروش برای شرکت‌های B2B (بزرگ‌ترین قراردادها)
**با:** `04-leads-sales` + `05-money-ops`
- `04-leads-sales/01` و `/02`: خط تولید لید + امتیازدهی AI. به شرکت‌هایی بفروش که تیم فروش دارند ولی داده ندارند.
- `04-leads-sales/10`: ارائهٔ اختصاصی برای هر لید → نرخ بردت بالا می‌رود.
- مدل درآمد: **پروژه‌ای + درصد/پاداش per لید**. قرارداد چند ده میلیونی است، نه چند میلیونی.
- داخل خودت هم بگذار: `04-leads-sales/09` + `/06` تا مشتری خودت را پیدا کنی.

> 📌 **قاعدهٔ ساده:** هیچ‌کدام از این‌ها خودش پول نمی‌سازد؛ **بسته‌بندی + مشتری** پول می‌سازد. ورک‌فلو فقط «زمان تیم» را صفر می‌کند تا بتوانی ۱۰ مشتری بگیری با تیم یک‌نفره.

## 🔌 وصل کردن به داشبورد CEO خودت

این ریپو از قبل زیرساخت واقعی دارد — از این‌ها استفاده کن تا ورک‌فلوها به CRM خودت وصل شوند:

| چی داری | مسیر | چطور از n8n صدا بزنی |
|---------|------|----------------------|
| وبهوک تلگرام | `POST /api/integrations/telegram/webhook` | گرهٔ `HTTP Request` با هدر `X-Telegram-Bot-Api-Secret-Token` |
| ارسال پیام | `POST /api/integrations/telegram/send` | `{"chatId":"…","text":"…"}` |
| Instagram (Meta) | `POST /api/integrations/instagram/webhook` | امضای `X-Hub-Signature-256` |
| باسلام | `lib/integrations/basalam.js` | از طریق API همین داشبورد |
| وضعیت همه | `GET /api/integrations/status` | مانیتورینگ ورک‌فلوها |

جزئیات: [`docs/TELEGRAM.md`](../docs/TELEGRAM.md) و [`docs/INSTAGRAM.md`](../docs/INSTAGRAM.md)

**الگوی پیشنهادی:** بخش «تولید و انتشار» را در n8n بگذار، و **CRM/لید/مشتری** را در داشبورد نگه دار.
n8n هر اتفاقی افتاد → یک `HTTP Request` به `/api/integrations/...` بزند → مشتری، پیام، Lead و Audit خودکار در CRM ثبت شود.

## ⚠️ نکات امنیتی و فنی

1. **هیچ ورک‌فلویی به‌صورت خودکار اجرا نمی‌شود.** همه با `active: false` ایمپورت می‌شوند.
2. توکن‌ها در فایل‌های JSON جا‌مانده نیستند (اکسپورت‌های n8n فقط ارجاع به Credential دارند) — ولی **خودت قبل از فعال‌کردن، متن فایل را یک نگاه بینداز**؛ در ورک‌فلوهای اپن‌سورس گاهی URL/شناسهٔ شخصی در گره‌ها جا می‌ماند.
3. گام‌های `Code` و `HTTP Request` را با داده‌ی خودت تست کن (Execute Node) قبل از فعال‌سازی زمان‌بندی‌شده.
4. ورک‌فلوهای «Scrape/Scraping» را با احتیاط استفاده کن — قوانین سایت‌ها و شرایط استفاده را رعایت کن.
5. برای شروع، فقط ۲ ورک‌فلو را فعال کن؛ زیاد‌روی می‌تواند سهمیهٔ API حسابت را بسوزاند.
