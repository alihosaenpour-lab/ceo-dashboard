## بخش ۱ — کجا اجراش کنم؟

n8n احتیاج به یک سرور دارد که **۲۴ ساعته روشن باشد** و **آدرس اینترنتی عمومی (HTTPS)** داشته باشد،
چون تلگرام و متا باید بتوانند به آن پیام بدهند.

| گزینه | خوبی | بدی | برای چه کسی |
|-------|------|-----|-------------|
| **کامپیوتر خودت + تونل** (ngrok / Cloudflare Tunnel) | رایگان، ۱۰ دقیقه‌ای | وقتی کامپیوتر خاموش شود، ربات خواب است | **برای شروع و یاد گرفتن** ⭐ |
| **VPS ایرانی** (مثلاً ابرآروان/پارس‌پک) | همیشه روشن، دسترسی داخلی راحت | ماهانه هزینه دارد | **برای کار جدی و مشتری** ⭐⭐ |
| **VPS خارجی** (Hetzner / Contabo) | ارزان، سرعت خوب | پرداخت ارزی می‌خواهد | اگر دسترسی ارزی داری |

### نصب سریع با Docker (روی VPS)
```bash
docker run -d --name n8n --restart unless-stopped \
  -p 5678:5678 \
  -e N8N_HOST=n8n.yourdomain.ir \
  -e N8N_PROTOCOL=https \
  -e WEBHOOK_URL=https://n8n.yourdomain.ir/ \
  -e N8N_SECURE_COOKIE=false \
  -v n8n_data:/home/node/.n8n \
  docker.n8n.io/n8nio/n8n
```
> ⚠️ `WEBHOOK_URL` را حتماً بگذار، وگرنه تلگرام نمی‌تواند وبهوک را پیدا کند.
> روی همان دامنه، SSL بگذار (Caddy یا Nginx + Certbot).

## بخش ۲ — ✈️ تلگرام را چطور وصل کنم؟ (۱۰ دقیقه، رایگان)

تلگرام **ساده‌ترین و ارزان‌ترین** راه شروع است. فقط یک توکن می‌خواهد.

### گام ۱ — ربات بساز
1. در تلگرام برو سراغ **[@BotFather](https://t.me/BotFather)**
2. بزن `/newbot`
3. اسم ربات را بده (مثلاً «دستیار فروش من»)
4. یوزرنیم بده که به `bot` ختم شود (مثلاً `MySalesAssistant_bot`)
5. BotFather یک خط می‌دهد شبیه این:
   ```
   7712345678:AAH9xK2mPqRsTuVwXyZ1234567890abcd
   ```
   **این توکن ربات توست. جایی منتشرش نکن.**

### گام ۲ — در n8n اعتبارنامه بساز
1. در n8n برو: **Credentials → Add Credential → Telegram**
2. `Access Token` را پیست کن (همان توکن BotFather)
3. **Save** — اگر سبز شد، تلگرام وصل است ✅

### گام ۳ — اولین ورک‌فلو را فعال کن
فایل `03-telegram/14-telegram-ai-bot-simple.json` را ایمپورت کن →
روی گره‌های `Telegram` اعتبارنامه بساز → **Active** را روشن کن.

n8n **خودش** وبهوک را در تلگرام ثبت می‌کند (لازم نیست دستی کاری کنی).
تست: در تلگرام به ربات خودت پیام بده. باید جواب بدهد.

### چک کردن اینکه درست وصل شده
```bash
curl "https://api.telegram.org/bot<TOKEN>/getWebhookInfo"
# باید ببینی: "url": "https://n8n-تو/webhook/..."
# و "last_error_message" نداشته باشد
```

### 📌 نکتهٔ قیمت
اگر ربات جواب نداد، احتمالاً کلید OpenAI را وصل نکرده‌ای. ربات‌های AI **دو** اعتبارنامه می‌خواهند:
`Telegram bot` + `OpenAI`. بدون OpenAI، ربات گیر می‌کند.

### ب) پست و ریلز اینستاگرام

4. **تصویر با Flux می‌سازد** (از طریق Replicate)
5. تصویر را در **اینستاگرام منتشر می‌کند** (Graph API)
6. نتیجه را در تلگرام برایت گزارش می‌دهد

**چی لازم دارد (همه‌شان اجباری):**

## بخش ۴ — 📸 اینستاگرام چه کاری برایم انجام می‌دهد؟ (و چطور وصلش کنم)

### این تیم برایت چه می‌کند
| ورک‌فلو | کار |
|---------|-----|

| `02-instagram-social/06-gdrive-to-instagram-tiktok-youtube` | ویدیو در گوگل‌درایو بگذار → خودکار در اینستا + تیک‌تاک + یوتیوب منتشر می‌شود |
| `02-instagram-social/02-ai-social-video-auto-post-instagram` | ویدیوی AI بسازد و در اینستا/فیسبوک/تیک‌تاک بگذارد |

**خلاصه: تولید + انتشار + زمان‌بندی، همه خودکار.** تو فقط تایید می‌کنی.

### چطور وصلش کنم (مراحل واقعی متا)
> اینستاگرام باید **Business یا Creator** باشد، نه شخصی. و باید به یک **صفحهٔ فیسبوک** وصل باشد.

1. **اینستاگرامت را بیزینس کن:** اپ اینستاگرام → Settings → Account type → Switch to Professional
2. **یک صفحهٔ فیسبوک بساز** و در اپ اینستاگرام: Settings → Linked accounts → Facebook را وصل کن
3. **اپ بساز:** برو [developers.facebook.com](https://developers.facebook.com) → My Apps → Create App →
   نوع **Business** را انتخاب کن
4. **محصول Instagram Graph API را اضافه کن** (در پنل اپ → Add Product)
5. **توکن بگیر:** از Graph API Explorer یا از طریق OAuth
   (شما به این مجوزها نیاز داری: `instagram_basic`, `instagram_content_publish`, `pages_show_list`)
6. **Instagram Business Account ID را بگیر:**
   ```bash
   curl "https://graph.facebook.com/v21.0/me/accounts?access_token=<TOKEN>"
   # page-id را بردار، بعد:
   curl "https://graph.facebook.com/v21.0/<PAGE_ID>?fields=instagram_business_account&access_token=<TOKEN>"
   ```
7. در n8n: **Credentials → Facebook Graph API** بساز و توکن را بگذار
8. در ورک‌فلو، `Instagram Business Account Id` را در گره‌های `Facebook Graph API` جای‌گذاری کن

> ⏳ توکن متا **کوتاه‌مدت** است (حدود ۱ ساعت). باید به توکن بلندمدت (۶۰ روزه) تبدیلش کنی و برای تمدید خودکار
> یک یادآور بگذاری. اگر این را جدی می‌گیری، ورک‌فلوی تمدید توکن را حتماً بساز.

## بخش ۷ — ⚠️ تله‌هایی که باید بدانی

1. **سرویس‌های پول‌دار:** ورک‌فلوهای ویدیو و تصویر از `Replicate`، `RapidAPI`، `Creatomate`، `Blotato`،
   `ElevenLabs`، `Kling` استفاده می‌کنند. **هر کدام اشتراک می‌خواهد.** با تلگرام و متن شروع کن (رایگان‌تر).
2. **متغیرهای محیطی:** بعضی ورک‌فلوها `$env.API_BASE_URL` می‌خواهند. در n8n برو
   Settings → Variables و آن‌ها را بساز، یا در گره جای‌گذاری کن:
   `API_BASE_URL`, `BASE_URL`, `TELEGRAM_CHAT_ID`, `IMGBB_API_KEY`
3. **کلید OpenAI از ایران:** اگر پرداخت/دسترسی نداری، هر سرویس **سازگار با OpenAI** کار می‌کند.
   در اعتبارنامهٔ OpenAI، فیلد `Base URL` را به آدرس آن سرویس عوض کن. (مدل‌های داخلی هم پشتیبانی می‌شوند)
4. **ورک‌فلوهای Scrape:** قوانین سایت‌ها و شرایط استفاده‌شان را رعایت کن. IP‌ات بلاک می‌شود و مسئولیتش با توست.
5. **اول تست، بعد فعال:** هیچ‌وقت ۱۰ ورک‌فلو را هم‌زمان فعال نکن. سهمیهٔ API می‌سوزد و
   نمی‌فهمی کدام خراب است. یکی‌یکی جلو برو.
6. **توکن‌ها را در Git نگذار.** n8n اعتبارنامه‌ها را در دیتابیس خودش نگه می‌دارد، ولی اگر ورک‌فلویی
   توکن را مستقیم داخل پارامتر گذاشته باشد (مثل `CRM Login` در ورک‌فلوی ۶)، آن را در جای امن نگه دار.
